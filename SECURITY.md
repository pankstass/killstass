# Границы безопасности killstass

- Только доверенная домашняя IPv4 LAN и, с v1.10 по желанию, tailnet Tailscale: Caddy и `firewall.sh` пропускают лишь сети из `KS_ALLOW_NETS` (по умолчанию — подсеть LAN). Это не hardened публичный игровой портал; порты 80/443 на роутере не пробрасываются.
- Пользователи разрешённых сетей могут регистрироваться без приглашения. Сайт не проверяет владение e-mail.
- Администраторов (с v1.9) назначает только оператор сервера (`scripts/admin.sh grant`); роль приложения не может менять `is_admin`. Администратор видит сводку, отзывы и пользователей, ведёт сезоны, достижения и экраны ТВ, выдаёт коды сброса пароля, но не меняет чужие матчи. Справочники — по-прежнему скриптами оператора и миграциями.
- Argon2id 32 MiB, t=2, p=1; не более двух одновременных операций хэширования в процессе.
- Серверные сессии — случайные 256-битные токены; в БД только SHA256. CSRF — отдельный случайный токен, точная проверка Origin.
- API не доверяет X-Forwarded-For; Caddy перезаписывает X-Real-IP. API/DB не публикуют порты.
- При ошибке версии пользователь явно согласует изменения. Не подтверждайте матч, не проверив счёт.
- Нет автоматического исполнения текста из справочников/заметок. Шаблоны JS экранируют HTML, CSP запрещает inline scripts и стили.
- Аватар (v1.10) — единственный загружаемый пользователем файл: только PNG/JPEG/WebP до 192 КБ, сигнатура должна совпасть с типом, стороны 16–512; браузер перед отправкой перекодирует картинку без EXIF. SVG и прочие файлы не принимаются; ответ — с `nosniff` и CSP. Скрытый профиль видят только сам игрок, его друзья и администраторы.
- Сброс пароля (v1.10): одноразовый код из 8 символов, в БД только SHA-256 с привязкой к аккаунту, срок `RESET_TTL_MINUTES` (60 минут), 5 неверных попыток на код, 10 запросов за 15 минут с IP; после смены пароля прочие сессии завершаются. Код показывается один раз — передавайте его лично. Код для другого администратора выдаёт только оператор.
- Ссылки экрана ТВ и личной ленты календаря — ключи-предъявители (192 бита): кто знает ссылку, видит без входа табло, таблицы и имена нескрытых игроков (ТВ) или вечера клуба (календарь), только из разрешённых сетей. Ключ календаря хранится хэшем, ключ ТВ — открыто (администратор может снова показать ссылку); удаление или замена сразу отзывает ссылку.
- CSV нейтрализует начальные =,+,-,@,табуляцию,CR в пользовательских строках, чтобы снизить риск формул при открытии в Excel.
- Приложение/прокси без root, read-only rootfs, cap_drop ALL, no-new-privileges. PostgreSQL запускается штатным entrypoint официального образа (с последующим postgres UID).
- .env не попадает в образ/репозиторий. Члены docker-группы уже обладают root-эквивалентом: они могут читать container env, dumps и volume.
- В бэкапах есть персональные данные и хэши паролей. Храните их зашифрованно вне хоста; не отправляйте в issues/чат. После восстановления сессии отзываются.
- В audit намеренно нет копий текста составов/заметок. Исправления очков не удаляются; actor_id обнуляется после удаления пользователя.
- В конфигурации нет внешних CDN, трекеров и почты. Push (v1.10) выключен по умолчанию: API по-прежнему без выхода в интернет и только пишет очередь `push_outbox`; отправляет её отдельный `pushworker` — единственный сервис с выходом наружу и только к push-службам браузеров из `PUSH_ALLOWED_HOSTS`. Содержимое шифруется ключом подписки (RFC 8291); VAPID-ключ сервера хранится в `app_settings` и попадает в дампы. Push-служба видит время и адрес подписки, но не текст.
- Сервис-воркер (v1.10) хранит в браузере оболочку версии и последние ответы API (матчи, профиль, друзья); копии удаляются при выходе, удалении аккаунта и ответе 401. Офлайн-очередь табло живёт в `localStorage` устройства до отправки. Не оставляйте вход на чужом устройстве.
- Домен и Let's Encrypt (v1.10): ключи API DNS-хостинга — в `local/acme.env` (0600), сертификаты — в `local/acme` (0700); оба не попадают в git, архивы выпуска и образы. lego запускается в контейнере без прав и с read-only rootfs. Ключ DNS API позволяет менять записи домена: по возможности выдавайте ключ только на нужную зону. A-запись публично раскрывает лишь частный адрес LAN.
- Tailscale (v1.10): маршрут только к `192.168.1.250/32`, ключ авторизации удаляется из `.env` после входа, состояние узла — в `local/tailscale` (0700; даёт подключение к tailnet от имени сервера, храните как пароль). Доступ получают все устройства tailnet — при чужих устройствах ограничьте его ACL Tailscale.
- Защита от физического доступа к HDD, компрометации root/роутера и заражённых клиентских устройств вне области приложения.

Перед любой внешней публикацией нужны отдельный threat model, обновление зависимостей, аудит, восстановление доступа и ограничения регистрации. Для удалённого домашнего доступа используйте VPN с явными правилами (с v1.10 — `scripts/tailscale.sh`), а не проброс портов.

1. **Локальное имя** — ✅ v1.10: домен `killstass.su` (`scripts/domain.sh`; A-запись на адрес в LAN или запись в DNS роутера), `APP_ORIGIN` — список origin, сертификат внутреннего CA Caddy до получения Let's Encrypt через DNS-01 (`scripts/cert.sh`, systemd timer продления).
2. **VPN** — ✅ v1.10: Tailscale (`scripts/tailscale.sh`) как subnet router только для `192.168.1.250/32`, без проброса портов; Caddy и `firewall.sh` пропускают явно перечисленные сети `KS_ALLOW_NETS` (LAN и `100.64.0.0/10`), не 0.0.0.0/0. Дальше: ACL tailnet по пользователям, WireGuard без стороннего координатора.
3. **PWA** — ✅ v1.10: сервис-воркер версии выпуска и офлайн-очередь табло: дедупликация по `request_id`, версия матча для ещё не отправленных команд, обычный `version_conflict`, время офлайн-нажатий часов (`at`), явная плашка «Нет связи». Новые матчи, вход и регистрация без сервера не работают.
4. **Push** — ✅ v1.10: `push_outbox` и `push_subscriptions` в той же транзакции, что `notify()`, отдельный `pushworker` (единственный сервис с выходом наружу, только к известным push-службам), VAPID-ключи в `app_settings`. В полностью изолированной LAN доставка по-прежнему не гарантирована: сообщения живут не дольше часа.
5. **Привязка гостей**: обязательное двустороннее согласие, отдельная таблица claims, аудит. Не менять старую «unconfirmed» запись в подтверждённую автоматически.
6. **Справочники**: импорт, provenance, новые миграции, Approved Ops 2025 и Game Sequence реализованы в v1.1. Дальше: сверить Strike Force Variel (Sweep & Clear сверена в v1.11, п. 11), получить разрешённый экспорт BattleKit для повторной перекрёстной проверки, админ-редактор с review, Community Maps только при ясных условиях использования, новые сезоны отдельными пакетами/кодами, расширенные исключения kill team и более полный ссылочный индекс Game Rules. Автообход внутренних запросов BattleKit и включение карт/полных faction rules в поставку не планируются (v1.7: полные тексты из общественных репозиториев загружает только администратор у себя).
7. **Аватар** — ✅ v1.10: браузер обрезает до 256×256 и перекодирует без EXIF, сервер принимает только PNG/JPEG/WebP до 192 КБ со сверкой сигнатуры и размеров; SVG не принимается.
8. **Сброс пароля** — ✅ v1.10: одноразовый код от администратора (`#admin`) или оператора (`scripts/admin.sh password`), в БД только хэш, 60 минут и 5 попыток. Самостоятельного восстановления по e-mail по-прежнему нет: e-mail — только альтернативный идентификатор входа, не подтверждённый адрес доставки.
9. **Большие сообщества**: keyset-pagination, индексы по профилю нагрузки, ограничение SSE на аккаунт, лимит регистрации всей LAN, модерация и резервные коды доступа (v1.9: страница `#admin` — только сводка, отзывы и поиск пользователей, без изменения чужих данных). Текущий стек рассчитан на небольшую домашнюю группу, не публичный сервис.
10. **Справочник правил с поиском** — ✅ v1.11: страница `#reference`. Из [warhammer-oracle](https://github.com/gregario/warhammer-oracle) (MIT) берутся только правила: 22 общих правила оружия (данные BSData) и обзор фаз (его авторы oracle ведут вручную — «не сверено»). Остальное — из прежних источников: команды, оперативники, правила фракций, ploys, снаряжение — BSData и kt-datacards (`import-teams.sh`), Tac Ops и миссии — каталог KILLSTASS. Правила загружает администратор (`scripts/import-rules.sh` или `update-reference.sh`, пакет с provenance: тег и коммит oracle, SHA-256 файлов, дата генерации), в поставку они не входят. Единый поиск — материализованное представление с FTS (`russian`) и `pg_trgm`, названия на обоих языках и кальки, «актуально», EN-оригинал + RU-пересказ, офлайн — по сохранённой в браузере библиотеке правил и каталогу. Отличие от плана: файлы данных oracle (`.ts`) читаются Python-кодом как данные — без Node-контейнера и без запуска кода oracle. Дальше: RU-пересказ фаз после сверки с Core Rules, поиск по сыгранным матчам и заметкам.

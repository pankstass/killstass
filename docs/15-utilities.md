# 15. v1.5.0 — кубики, «Поделиться», демо, обратная связь

Этап 5 плана приближения к BattleKit. Без внешних сервисов: всё работает в LAN, без Telegram, CDN и внешних шрифтов (CSP `self`).

## Кубики

- Панель «Кубики» в идущем матче и в демо: 1d6…6d6 одним нажатием или N (1–20), «Успех на» 2+…6+, сумма, число успехов и шестёрок. Шестёрки выделены акцентом, единицы — красным пунктиром.
- Нажатие на кубик выбирает его; «Перебросить выбранные», «Перебросить промахи».
- «Бросить на инициативу» в блоке «Кто получил инициативу?»: по 1d6 каждому, ничьи перебрасываются автоматически, показывается, кто выигрывает бросок. Отметку инициативы игроки делают сами — победитель броска решает, кому её отдать.
- Генератор: `crypto.getRandomValues` с отбрасыванием значений ≥ 252 (равномерный d6 без смещения). Броски только на устройстве и не записываются на сервер: клиентский результат нельзя проверить, поэтому он не выдаётся за доказательство в аудите.

## Поделиться результатом

Панель «Поделиться результатом» появляется после завершения матча (ожидает подтверждения, подтверждён, спор, без подтверждения).

- «Поделиться текстом» — системное меню Web Share или копирование: миссия, счёт, победитель, статус, дата.
- «Картинка PNG» — карточка 1200×630, рисуется локально (canvas). На телефоне с поддержкой Web Share файлов — сразу в меню «Поделиться», иначе превью и «Скачать картинку».
- «Ссылка для просмотра» — `https://<сервер>/#shared/<токен>`: итог без входа для любого устройства в LAN. На сервере хранится только SHA-256 токена; ссылка показывается один раз (в рамках открытой страницы). Новая ссылка заменяет прежнюю, «Отозвать ссылку» отключает её сразу. Если матч снова открыт (спор → правки), ссылка не работает, пока матч не завершён снова.
- Публичный итог содержит: имена, команды, миссию, зону, редакцию, дату, VP по поворотам, Crit/Tac/Kill и бонус основной операции (для Approved Ops), итог по часам. Не содержит: ID пользователей, public ID, заметки, составы.

## Демо без входа

- На экране входа — «Попробовать без входа (демо)», адрес `#demo`. Работает и для вошедшего пользователя.
- Табло на два игрока: имена, TP1–TP4, Crit/Tac/Kill VP по поворотам, CP, инициатива (с броском), основная операция, «Подсчитать итог», кубики.
- Хранится только в `localStorage` этого браузера (`killstass-demo`), на сервер ничего не отправляется, в журнал и статистику не попадает. Плашка «Демо» видна всегда.
- Подсчёт упрощён: бонус основной операции = ⌈min(VP операции, 6) / 2⌉, лимиты правил не проверяются. Настоящий матч считает сервер.

## Обратная связь

- Профиль → «Обратная связь»: до 2000 символов, лимит 10 сообщений / 15 мин / IP. Сохраняется в таблицу `feedback` этого сервера.
- Читает только оператор сервера: до v1.9 — `./scripts/feedback.sh` (открытые), `./scripts/feedback.sh all` (последние 100), `./scripts/feedback.sh done ID` (отметить обработанным); с v1.9 скрипт удалён, отзывы — на странице `#admin` (доступ: `./scripts/admin.sh grant LOGIN`).
- При удалении аккаунта его сообщения удаляются (каскад).

## API

| Метод и путь | Права | Ответ |
|---|---|---|
| GET /matches/{uuid}/share | участник | `active`, `created_at` |
| POST /matches/{uuid}/share | участник, матч завершён | 201 `token` (новая ссылка заменяет прежнюю); 409 `share_unavailable` |
| DELETE /matches/{uuid}/share | участник | 200 |
| GET /shared/{token} | без входа; 120 / 15 мин / IP | итог матча; 404 `share_not_found` |
| POST /feedback | сессия; `message` 1–2000, `page` ≤ 200 | 201 |

Создание ссылки намеренно не идёт через таблицу идемпотентности `operations`: там результат хранится дословно, а токен не должен храниться в открытом виде. Повтор запроса просто выдаёт новую ссылку.

## База данных — 008_share_feedback.sql

- `match_shares(token_hash PK, match_id UNIQUE, created_by, created_at)` — одна ссылка на матч, каскад при удалении матча.
- `feedback(id, user_id → users ON DELETE CASCADE, page, message, created_at, handled_at)`, частичный индекс открытых сообщений.

## Тесты

- `tests/test_share_feedback.py`: ссылка недоступна до завершения; публичный итог без входа без ID/заметок/составов; основная операция раскрыта после завершения; замена ссылки отключает прежнюю; отзыв; в БД только хэш; не участник — 404; обратная связь: валидация, лишние поля, удаление вместе с аккаунтом.
- Браузер (Chromium 390×844): демо без входа (счёт, бросок на инициативу, 5d6 с перебросом, итог, сохранение после перезагрузки), завершённый hot-seat → картинка PNG, ссылка открыта в другом браузере без входа, отзыв → «Ссылка недоступна», отправка обратной связи; регрессия v1.2–v1.4.

## Не входит

Часы в демо, запись бросков на сервер, QR-код ссылки, админ-интерфейс обратной связи в браузере (только скрипт оператора).

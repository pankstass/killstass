# 16. Английский интерфейс (v1.6.0)

## Что сделано

- Переключатель **RU / EN**: в верхней панели, на экране входа, в профиле и на страницах без входа (`#demo`, `#shared/…`). Выбор хранится только в этом браузере (`localStorage["killstass-lang"]`); по умолчанию — русский. После переключения страница перезагружается.
- Словари интерфейса: `web/i18n/ru.json` и `web/i18n/en.json` — одинаковый набор ключей, включая `errors` (коды ошибок API → текст). Атрибут `<html lang>`, формат дат и чисел (`ru-RU` / `en-GB`, часовой пояс Europe/Moscow) следуют языку.
- Английские названия и краткие описания справочника: `web/i18n/catalog.en.json` — оверлей по `code` для `catalogs` (label, `config.summary`, `config.reveal`) и `game_sequence` (phase, label, description). Если перевода нет, показывается русское значение из БД. Тексты — редакторский пересказ, не официальные карточки.
- Публичная страница результата получает из `/api/shared/{token}` дополнительно `mission_code`, `killzone_code` и `players[].team_code`, чтобы показать английские названия без входа.
- Статистика (команды, миссии, killzone, Tac Ops) берёт название по id из локализованного справочника; личные встречи — имя игрока.
- Поиск по краткой справке правил в английском режиме фильтрует переведённые записи на клиенте (серверный индекс русский).
- Добавлены переводы ранее отсутствовавших кодов ошибок (`date_invalid`, `turn_invalid`, `challenge_not_found` и др.) — раньше они показывались как общее «Запрос не выполнен».

## Без изменений

- Миграций нет (health по-прежнему ожидает 8). Новых переменных `.env` нет.
- Экспорт CSV/JSON и данные в БД остаются на русском; в английском режиме под кнопками экспорта есть пояснение.
- Имена игроков и заметки не переводятся.

## Проверка

- `tests/test_i18n.py`: одинаковые ключи ru/en, нет кириллицы в английских строках, все ключи `t("…")` из JS есть в словаре, каждый код `fail(…, 'code')` из API переведён, `catalog.en.json` покрывает все активные записи справочника и последовательности игры.
- E2E (Playwright, 390×844): экран входа, демо, обзор, создание hot-seat матча, табло, последовательность игры, поиск правил, статистика и профиль на английском без кириллицы (кроме имён игроков); обратное переключение на русский.

## Как добавить перевод новой записи справочника

Добавьте запись в `catalog.en.json` с тем же `code`, что в БД. Тест `test_english_catalog_covers_active_codes` упадёт, если активная запись осталась без перевода.

# 1.14.1 — восстановление загрузки

При загрузке 1.14.0 браузер мог запросить много модулей одновременно. При лимите uvicorn 32 часть запросов могла получить 503; Caddy добавлял к таким ответам заголовок immutable, и браузер мог сохранить ошибку. На конкретном сервере это следует подтвердить по журналу API и сетевым запросам.

- Лимит uvicorn повышен до 256 соединений, backlog — до 128; установка service worker загружает ресурсы группами по 8.
- Длительное кэширование ставит API только успешным версионированным файлам; для ошибок статики и ответов без собственного Cache-Control — no-store.
- Независимая защита запуска показывает действия «Обновить» и «Починить». Восстановление удаляет только кэши оболочки killstass, не удаляет service worker и пытается перезагрузить файлы в HTTP-кэше. Офлайн-данные и очередь изменений не удаляются.
- Если открыть недоступную страницу после входа, отображается ошибка и ссылка в Штаб. Smoke-проверка проверяет все файлы JavaScript текущей версии.

Миграций нет. Инструкция обновления и отката — в UPDATE-INFO.md.

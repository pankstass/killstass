# 4. Визуальный гайд killstass

Полный CSS — `web/style.css`. Оригинальные `web/logo.svg`, `web/icons.svg`, favicon и manifest включены. Иллюстрации/символы/логотипы Games Workshop и оформление BattleKit не используются.

## v1.9: трекер, калькулятор, печать, доступность

Витрина `#styleguide` (без входа, `web/styleguide.js`) показывает все токены обеих тем, типографику, кнопки, бейджи, поля, иконки, эмблемы, половину табло, датакарты, QR и пример печати — с неё удобно начинать проверку правок CSS. Новые разделы `style.css` подписаны `v1.9 — …`.

| Компонент | Назначение |
|---|---|
| `.tracker` → `.ops` → `.op` (`.op-main`, `.op-name`, `.op-w`, `.pips`, `.op-controls` с `.order`/`.act`) | трекер оперативников под половиной игрока; выведенный — зачёркнут, кнопки выключены; `.op-add`/`.op-add-form` — добавление |
| `.undo`, `.auto-note` | кнопка «Отменить» на полосе табло; пометка «считается по трекеру» у убийств |
| `.board.tabletop` | режим стола: половины в колонку, верхняя (и её сторона часов) повёрнута на 180° |
| `.bump` | короткое «подпрыгивание» изменившихся VP (`ks-bump`); вместе с `button:active` — только при `prefers-reduced-motion: no-preference` |
| `.attack-form`, `.atk-profile`, `.atk-stats`, `.atk-dist`, `.atk-roll`, `.die`, `.atk-damage` | калькулятор атаки: профили, ожидание, гистограмма урона (столбцы от числа ран — `.kill`), кубики броска |
| `.roster-panels`/`.roster-panel`, `.datacards`/`.datacard` (`.dc-stats`, `.dc-weapons`, `.dc-rule`, `.dc-action`, `.dc-keywords`) | ростеры в матче и датакарты |
| `.invite-qr`, `.qr` | QR-код приглашения (SVG, тёмные модули на белом с тихой зоной в обеих темах) |
| `.ratings`, `.standings` (`tr.me`, `tr.dropped`), `.t-round`, `.t-players`, `.t-actions`, `.t-result-form`, `.t-report` | Elo, турнирная таблица, туры и ввод результата |
| `.feedback-item`, `.kv` | страница администратора: отзывы, сводка «ключ — значение» |
| `.emblem`, `.emblem-svg` | эмблема команды (`web/emblem.js`): шестиугольник в цветах семейства фракций и символ архетипа, собственная геометрия |
| `#print-root` + `@media print` | печать ростера: только карточки, две в ряд на A4, интерфейс скрыт; на экране не виден |

Доступность (проверяется axe-core, WCAG 2.1 A/AA, в обеих темах): токен `--danger-ink` — текст на `--danger` (белый в светлой теме, тёмный в тёмной); видимая рамка `:focus-visible` у кнопок, ссылок и полей; `.sr-only` — текст только для экранного диктора (например, «Карточка: » перед именем оперативника, чтобы подпись кнопки начиналась с видимого текста); прокручиваемые `.table-wrap` получают `tabindex="0"`; цвет активированной кнопки игрока сохраняется под указателем. Неиспользуемые правила (старые счётчики, `.full`, табло последовательности, лишние правила часов/кольца/бейджей) удалены; снимки DOM и вычисленных стилей до и после совпали.

## v1.8: табло матча и конструктор ростеров

Табло (`web/board.js`, раздел `v1.8 — BattleKit-style match board` в `style.css`) повторяет только раскладку привычного табло: две половины игроков, полоса поворотов, крупные VP/CP. Графика, шрифты и тексты BattleKit не используются — все иконки собственные (`icons.svg`: skull, shield, dice, clock, flag и др.).

| Компонент | Назначение |
|---|---|
| `.board`, `.board-bar` (`.bar-top`, `.bar-controls`) | экран матча и верхняя полоса: TP, инициатива, часы, меню |
| `.halves` → `.half.slot-1/.slot-2` | половина игрока: `.half-banner` (имя, команда, `.half-vp`), `.boxes`, `.half-bottom`; соперник в матче с другом — только чтение |
| `.box`, `.box-label`, `.cell-num`, `.stepper` | плитки Crit/Tac/Kill/CP со степпером ±; недоступное — штриховка `.na` |
| `.tokens` → `.token` | жетоны и метки на поле; `.chip-row`/`.chip` — Tac Op (скрытый в hot-seat) и статусы |
| `.kill-box`, `.kill-row`, `.kill-step` | убийства с учётом размера команды соперника |
| `.clock-board` (`.clock-side`, `.clock-big`, `.clock-mode`) | часы на табло, крупная плитка передачи хода |
| `.menu`, `.board-sheet`, `.sheet-close` | меню действий и нижний лист (итог, завершение, заметки TP) |
| `.hex` | шестиугольник номера TP через `::before` + `clip-path` |

Новые токены: `--ok` (успех, «ростер в порядке»), `--p1-solid`/`--p2-solid` (заливка половины игрока), `--p1-bar`/`--p2-bar` (светлый цвет игрока на тёмной полосе).

Конструктор ростеров (`web/rosters.js`, раздел `v1.8 — roster builder`): `.roster-tile` — карточка ростера в списке; `.roster-layout` — две колонки (слева выбор `.add-list`/`.add-op`, справа ростер `.rcard`), на ≤1099 px — одна колонка с горизонтальной лентой чипов добавления; `.rcard` — оперативник с `.ropts` (группы `.opt-group`, варианты `.opt`, переключатель ✓ или радио «выбрать один»), `.statline` и `.opt-profiles`; `.limits`/`.limit` — счётчики лимитов, `.issues` — ошибки и предупреждения, `.save-state` — статус автосохранения. Варианты правил фракции на странице команды — `.rule-options`/`.rule-option`, примечание об источнике — `.src-note`.

Радиусы: карточки 14 px, поля и кнопки 8 px, бейджи и вкладки — «таблетки». Тень только в светлой теме (1–3 px). Шкала отступов 4/8/12/16/20/24/32. Кнопки и поля 44 px (в верхней панели 36 px), сегменты поворотов 48 px.

Шрифты: заголовки, счёт, метрики, часы и кубики — локальный поднабор PT Sans Narrow Bold (CSS `Heading`, табличные цифры); текст — системный sans-serif (`system-ui`, Segoe UI, Roboto, Noto Sans, Arial); ID — Liberation Mono (`Terminal`). Без внешних запросов.

Раскладка: фиксированная верхняя панель (`.topbar`, 56 px, оранжевая линия 3 px) с логотипом, именем, RU/EN и ◐; `.sidebar` 220 px под ней (200 px при ≤1000 px); на телефоне ≤720 px — нижнее меню 64 px из 6 пунктов, верхняя панель 52 px. Контент до 1180 px.

Компоненты: `.panel` — карточка; `button`/`.button` — основное действие; `.secondary` — вторичное (белое с серой рамкой); `.danger` — красная рамка; `.badge` — статус-таблетка (`.active` — оранжевая); `.turns` — сегментированный переключатель (`.selected` — залитый); `.player.slot-1/.slot-2` — цветная полоса игрока, `.leader` — обводка его цветом; `.metric` — число+подпись; `.warning` — светло-оранжевая плашка с левой линией; `.tabs a[aria-current]` — тёмная таблетка; `.datacard` — шапка `--bar`, 4 плитки `.dc-stats`, таблица `.dc-weapons`, `.dc-rule`/`.dc-action`, подвал с ключевыми словами; `.team-tile` — плитка команды.

Тема: по умолчанию системная (`prefers-color-scheme`), выбор ◐ хранится в `localStorage["killstass-theme"]`.

Доступность: подписанные поля, видимый фокус (3 px), aria-current у меню и вкладок, aria-live для уведомлений, семантические таблицы, reduced-motion; цвет игроков дублируется подписью «Игрок 1/2», расхождение данных — текстом, а не только цветом.

## v1.1: Game Sequence и операции

Существующие токены/локальные шрифты не изменены. Новая .sequence-panel использует --panel/--accent/--line; ширина 380 px на desktop (>1100 px), справа от уменьшенной рабочей области. На планшете 721–1100 px нижняя панель занимает рабочую область справа от исходного меню. На экране ≤720 px — нижняя панель 45dvh над навигацией, рабочая область отдельно прокручивается в оставшейся высоте; панель не накладывается поверх счёта/формы. В active при открытии рабочая область прокручивается к табло. Чекбокс имеет подпись-цель не менее 44 px, кнопка закрытия ≥44×44, Escape возвращает фокус кнопке. Панель немодальная: нет блокировки остальных элементов/фокус-ловушки. Выполненные шаги дополнительно перечёркнуты, не только окрашены. Движение отключается через prefers-reduced-motion. Сброс чек-листа и поиск правил внизу панели; все UI-строки в ru.json, игровой текст — данные БД.
